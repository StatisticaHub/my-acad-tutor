## Course philosophy

The course uses a shared diabetes prediction setting across early modules so learners can see how modelling ideas develop gradually:

1. prediction question
2. supervised learning
3. logistic regression
4. train/test validation
5. ROC/AUC
6. calibration
7. regularisation
8. case-study reporting
